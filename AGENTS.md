# AGENTS.md — e-commerce_theme

## What this is
Basic e-commerce HTML/CSS/JavaScript theme (ShopGrids free lite). Static frontend theme with product pages, cart, checkout.

## Stack
- HTML5 / CSS3 / JavaScript
- jQuery / Bootstrap

## Run
Open `index.html` in a browser or serve via any static web server.

## Structure
- `index.html` — homepage
- `assets/` — CSS, JS, images
- `product-*.html` — product listing/detail pages
- `cart.html`, `checkout.html` — e-commerce flow
- `ShopGrids-free-lite/` — original theme source

## Conventions
- No comments in code unless asked.
